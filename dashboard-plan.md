# Pika Workspace Dashboard

The dashboard should make four actions obvious without feeling like a generic analytics product: **search a question**, **scan useful conversations**, **watch a topic**, and **save a thread**. It uses one persistent charcoal sidebar, a light working canvas, compact status chips, and coral/violet accents reserved for active states and useful new activity.

The main view leads with a plain-language search prompt, a concise result stream, and a right rail for topic watchlists and saved threads. Searches update the visible results in-browser, save buttons move results into the saved state, and watchlist controls can be toggled without leaving the page. On mobile, the sidebar condenses into a top workspace bar, while search and results remain first in reading order.

## Dashboard Sections

| Area | Job |
| --- | --- |
| Workspace navigation | Move between Search, Watchlist, Saved, and Guides. |
| Search composer | Ask Pika a practical question in ordinary language. |
| Result stream | Review conversations, identify people, and save useful threads. |
| Watchlist | Keep a short list of topics and highlight new posts. |
| Saved threads | Revisit conversations selected for later. |
