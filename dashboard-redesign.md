# Reference-Inspired Pika Dashboard Redesign

The supplied reference establishes the dashboard’s **material and composition**, not its product semantics. Pika retains conversation search, watchlists, alerts, and saved threads, but presents them inside a warm taupe workspace panel with translucent off-white cards, thin white keylines, deep ink typography, and a dark editorial activity module.

## Pika Translation

| Reference cue | Pika interpretation |
| --- | --- |
| Warm, luminous canvas | Peach-to-stone backdrop with low-contrast orbital line details. |
| Framed glass workspace | A rounded soft-glass application surface that contains navigation and content. |
| Compact summary row | Search status, watched topics, and saved threads, without invented aggregate metrics. |
| Prominent central analysis module | “Conversation pulse” view with a concrete topic mix and ranked useful threads. |
| Dark right-rail schedule card | “New conversations” activity feed for topics a user is watching. |
| Lower table | A practical conversation list with source, topic, relevance, and save action. |

The page keeps local search, saving, and watch toggles intact. On narrow screens, the glass workspace becomes full-width while the visual hierarchy remains: summary, pulse, activity, and conversation list.
